
# UTP Assistant Chatbot

Proyecto basado en la TA2:
Diseño de UTP Assistant para automatización empresarial.

Características:
- Chat con IA.
- Procesamiento de correos.
- Extracción de requisitos.
- Respuestas profesionales.
- Arquitectura preparada para Function Calling.

Ejecutar:

1. Instalar:
pip install -r requirements.txt

2. Configurar API Key.

3. Ejecutar:
streamlit run app.py

Modelo utilizado:
gpt-4o-mini por velocidad y menor costo.
